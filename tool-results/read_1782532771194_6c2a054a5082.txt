   416→   416→2.10 SGTX Trade Trust Passport™
   417→   417→
   418→   418→2.10.1 Purpose
   419→   419→
   420→   420→Provide a portable, participant‑controlled institutional trust
   421→   421→profile that aggregates a tenant's reliability, compliance, financing
   422→   422→performance, dispute resolution, and verified identifiers. The Trust
   423→   423→Passport is a verifiable credential (W3C standard) signed by SGTX,
   424→   424→enabling participants to share their trustworthiness with
   425→   425→counterparties, financiers, logistics providers, and regulators without
   426→   426→exposing raw trade data.
   427→   427→
   428→   428→Key principles (non‑marketplace, sovereign):
   429→   429→
   430→   430→-   Participant‑controlled: No automatic sharing. Every share requires
   431→   431→    explicit consent.
   432→   432→
   433→   433→-   Privacy‑preserving: Passport contains aggregated scores and
   434→   434→    summaries, not transaction‑level details.
   435→   435→
   436→   436→-   Verifiable off‑line: Passport includes a cryptographic signature
   437→   437→    that can be verified using SGTX's public key.
   438→   438→
   439→   439→-   Revocable: Sharing links can be revoked at any time; old links
   440→   440→    become invalid immediately.
   441→   441→
   442→   442→-   No ranking or discovery: The Passport never suggests "better"
   443→   443→    counterparties; it only reflects the tenant's own verified history.
   444→   444→

   623→   623→2.10.4 Sharing Workflow (One‑Click)
   624→   624→
   625→   625→Step 1 — Generate Passport:
   626→   626→Tenant admin navigates to Company Admin → Trust Passport and
   627→   627→clicks "Generate Passport" (one click).
   628→   628→
   629→   629→-   System creates a new verifiable credential.
   630→   630→
   631→   631→-   Passport is valid for 90 days (configurable per tenant).
   632→   632→
   633→   633→-   Admin sees a summary card with TRI, confidence, and expiration.
   634→   634→
   635→   635→Step 2 — Share with Counterparty:
   636→   636→Admin clicks "Share Passport" → selects the recipient's GTID (from saved
   637→   637→contacts) or chooses "Anyone with link" (anonymous token).
   638→   638→
   639→   639→-   If specific GTID, the system verifies that the recipient is an
   640→   640→    existing counterparty.
   641→   641→
   642→   642→-   Admin selects which dimensions to share.
   643→   643→
   644→   644→-   Click "Generate Link" → system returns a one‑time token URL.
   645→   645→
   646→   646→-   Admin copies link and sends to recipient (outside SGTX).
   647→   647→
   648→   648→Step 3 — Recipient Verification:
   649→   649→Recipient opens the link (no login required).
   650→   650→
   651→   651→-   Page displays the passport data (only the dimensions the sharer
   652→   652→    consented to).
   653→   653→
   654→   654→-   Recipient can download signed JSON or copy a verification code to
   655→   655→    check offline.
   656→   656→
   657→   657→-   The page shows a green checkmark if the signature is valid and the
   658→   658→    passport is not revoked or expired.
   659→   659→
   660→   660→Step 4 — Revoke Access:
   661→   661→At any time, admin clicks "Revoke" next to the shared token.
   662→   662→
   663→   663→-   Revocation is immediate.
   664→   664→
   665→   665→-   Any subsequent attempt to verify that token returns { "valid":
   666→   666→    false, "reason": "revoked" }.
   667→   667→
   668→   668→One‑click guarantee: Generate Passport (1), Share (1), Revoke (1).
   669→   669→
   670→   670→2.10.5 Offline Verification & Public Key
   671→   671→
   672→   672→Any party can verify a Trust Passport offline using the SGTX public key.
   673→   673→
   674→   674→Steps (for recipient):
   675→   675→
   676→   676→1.  Download the signed passport JSON.
   677→   677→
   678→   678→2.  Use the open‑source tool trust-verify (provided by SGTX).
   679→   679→
   680→   680→3.  Verify signature and check that expires_at is in the future.
   681→   681→
   682→   682→Public keys are published
   683→   683→at: https://sgtx.io/.well-known/sgtx-keys (Ed25519 and optional
   684→   684→Dilithium3 for archival).
