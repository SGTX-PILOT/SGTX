3B.2.8 Draft AutoSave – Zero Clicks

Draft expiry: 14 days of inactivity; reminders at 11 and 13 days. Expired drafts can be restored via Company Admin → Drafts (admin only).
Oneclick guarantee: No user action needed for autosave. One click to resume draft.

3B.3.5.4 Combining Mode B and Mode C – Best of Both
Seller action: For the same trade, the seller can use:
• Mode B to get trucking quotes from local LSPs.
• Mode C to get ocean freight quotes from shipping lines.
• Mode A for any service where seller already has a fixed rate.
Example:
• Ocean freight: Mode C → select MSC and Maersk → both quote.
• Trucking: Mode B → broadcast to 5 local trucking companies → receive quotes.
• Customs broker: Mode A → fixed rate $150 (or Mode B if needed).
Comparison panel shows all received quotes grouped by service. Seller selects the best option for each service independently.
Oneclick guarantee: No extra complexity – seller selects quotes per service as they arrive. The system automatically aggregates selected costs.
Governance: Governor ensures that for each mandatory service (based on incoterm), at least one quote is selected (either from Mode A, B, or C)
before quote submission.

3B.3.8 SGTX Platform Fee Calculation – One Click (Automatic)
• Total trade value (before fee) = EXW total + total logistics costs (as defined by incoterm).
• Fee rate = 1.5% (fixed per global model).
• SGTX fee amount = Total trade value × 1.5%.
• Final quoted price to buyer = Total trade value + SGTX fee.
Display to seller: Clear breakdown (EXW, logistics, SGTX fee, final price).
Display to buyer (later): Total price with note “(includes SGTX platform fee of $X)”.
Oneclick: No separate click – automatically calculated when seller assembles quote.
3B.3.9 Submit Quote Package – One Click
Seller final action: Click “Submit Quote” – one click.
Governor validation (A4):
• All mandatory fields present.
• Packing plan locked (including nonuniform layers validated).
• For multishipment: schedule fully defined, each shipment validated.
• Alternative ports valid.
• SGTX fee correctly calculated and added.
• For each mandatory service (based on incoterm), a quote is selected (from Mode A, B, or C).
If ALLOW:
• Trade status → QUOTED.
• Quote package (including all delivery options, multishipment schedule, alternatives, peroption fees) stored
in seller_quotes, quote_delivery_options, seller_quotes.counter_schedule.
• Buyer receives Smart Inbox item (priority 75) with comparison table.
• Seller receives confirmation.
If CONDITIONAL or DENY:
• Governor returns plainlanguage tenant_message ( A1, Groq) with condition checklist and oneclick remediation links.
• Seller fixes issues, clicks “Retry” – one click to resubmit.
Oneclick guarantee: Seller clicks “Submit Quote” once. If blocked, each condition has a oneclick link. After fixing, one click to resubmit.
